Scopes allow you to restrict permissions at a finer level within a route. They only need to be declared for routes where you want to grant different permissions depending on the context or data subset. For example, the GET /preferences route uses scopes to control which resource's preferences a role can retrieve — a routes scope grants access to route datagrid preferences, while a roles scope grants access to role datagrid preferences. Each role is then given only the scopes it needs.
