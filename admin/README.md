# Admin

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.1.1.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

For the full stack (Gatelin + mocks + Traefik), prefer starting from the repo root:

```bash
./scripts/start-dev.sh
```

Admin is then available at `http://localhost:8100/gatelin/`.

## Running end-to-end tests

E2E tests use [Playwright](https://playwright.dev/) against the docker-compose stack (Traefik on port 8100).

1. From the repo root, set up and start the stack:

```bash
./scripts/setup-env.sh
./scripts/setup-mocks.sh
./scripts/start-dev.sh
```

2. From `admin/`, install the browser once and run the suite:

```bash
npm run e2e:install
npm run e2e
```

Interactive UI mode:

```bash
npm run e2e:ui
```

Credentials default to `admin@example.com` with the password generated by `setup-mocks.sh` (read from `swagger/src/gatelin.openapi.json`). Override with:

```bash
E2E_EMAIL=admin@example.com E2E_PASSWORD='…' npm run e2e
E2E_BASE_URL=http://localhost:8100/gatelin/ npm run e2e
```
