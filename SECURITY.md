# Security Policy

## Supported versions

Security updates are provided for the latest Gatelin release.

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/ALTEN-group/Gatelin/security/advisories/new) to share the affected component, reproduction steps, impact, and any suggested mitigation.

The maintainers will acknowledge the report, investigate it, and coordinate disclosure and remediation through the private advisory.
